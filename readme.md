Информация о проекте: почта для повседневного испльзования.

## 🚀 Основной функционал

- **Личный кабинет & Безопасность:** Регистрация, авторизация и кастомизация настроек профиля (смена паролей, аватаров).
- **Почтовый сервис:** Создание, отправка, хранение и структурирование писем (`letters`).
- **База данных (ORM):** Использование SQLAlchemy для работы с реляционной БД (пользователи, сообщения, сессии).
- **Telegram Bot:** Синхронизированный бот для получения мгновенных уведомлений о новых входящих сообщениях и управления базовыми функциями.

## 📁 Структура репозитория

```text
Site-main/
├── data/                    # Модели базы данных и сессии
│   ├── db_session.py        # Инициализация и подключение к БД
│   ├── users.py             # Модель пользователя (User)
│   └── letters.py           # Модель сообщений/писем (Letter)
├── db/                      # Директория с файлом базы данных SQLite
├── forms/                   # WTForms для валидации ввода
│   └── user.py              # Формы регистрации и авторизации
├── static/                  # Статические файлы (CSS стили, изображения)
├── templates/               
├── main.py                  # Главный файл запуска Flask-приложения
├── tg_bot.py                # Скрипт Telegram-бота (aiogram / telebot)
└── requirements.txt         # Список зависимостей проекта
```

## 🛠️ Установка и запуск

1. **Клонируйте проект и перейдите в него:**
   ```bash
   git clone https://github.com
   cd MailWorld-Site
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Настройте конфигурацию:**
   - Создайте или обновите токен бота в конфигурационных файлах `config.txt` / `app_key.txt`.

4. **Запустите веб-сайт:**
   ```bash
   python main.py
   ```

5. **Запустите Telegram-бота (в отдельном терминале):**
   ```bash
   python tg_bot.py
   ```
